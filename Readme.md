# Mushroom Classifier — Usage & Inference

Lightweight image classifier for mushroom quality and growth-stage detection. This README focuses on how the repository's files work for inference (running and converting the model) and how to use the included frontend.

**Files and purpose:**
- `classify.py`: Flask-based inference API. Loads `mushroom_classifier.h5` and exposes `POST /predict` which accepts a form file field named `file`.
- `index.html`: Simple browser frontend that uploads an image to `http://127.0.0.1:5000/predict` and displays the returned prediction.
- `mushroom_classifier.h5`: The trained Keras model used for inference (included in the repo).
- `mushroom_classifier.tflite`: TFLite version of the model (generated by `convert.py` / `convert_onnx.py` if you convert it).
- `convert.py`: Converts `mushroom_classifier.h5` to TFLite using TensorFlow Lite converter.
- `convert_onnx.py`: Currently also converts the `.h5` to TFLite (name is misleading — it does not produce an ONNX file).
- `train.py`: Training script (kept for reference) — not required to run inference.

## Quick start — run the API and web UI

1. Install minimal dependencies (example):

```powershell
pip install tensorflow flask flask-cors numpy pillow
```

2. Start the inference server:

```powershell
python classify.py
```

3. Open `index.html` in a browser (double-click or serve it) and upload an image. The page sends the image to `http://127.0.0.1:5000/predict` and shows the result.

Or, test the API directly with `curl`:

```bash
curl -X POST -F "file=@/path/to/image.jpg" http://127.0.0.1:5000/predict
```

Example JSON response:

```json
{
  "prediction": "Good Mushroom Detected",
  "confidence": "87.32%"
}
```

If the model's top confidence is below 60%, the API returns `"Uncertain Detection"` for `prediction`.

## How `classify.py` works (summary)

- Receives uploaded image as `file` in a multipart form request.
- Saves the file temporarily as `temp.jpg`, loads it with target size `(224, 224)`, converts to an array and normalizes by `/255.0`.
- Runs `model.predict(...)` on a single-batch image and finds the highest-scoring class.
- If max confidence < 60% the code returns `Uncertain Detection`; otherwise it maps the model class to a human-friendly label.
- The temporary file is removed after prediction.

## Converting the model to TFLite

Run either converter script to generate `mushroom_classifier.tflite` from the `.h5` model:

```powershell
python convert.py
# or
python convert_onnx.py
```

Note: `convert_onnx.py` currently uses the TFLite converter as well — it does not output ONNX.

## Dataset and classes

This project was trained on the `mashrooms_dataset/` folder with these label directories:

- `bad mash`, `buds`, `good`, `intermediate`, `mature`, `medium`, plus a `no mashroom detected` handling in the API.

## Notes

- The API listens on the default Flask host/port (`127.0.0.1:5000`) when run as `python classify.py`.
- The frontend expects the backend at `http://127.0.0.1:5000/predict` (CORS is enabled in `classify.py`).
- If you plan to deploy publicly, run Flask with a production WSGI server and secure the upload endpoint.
